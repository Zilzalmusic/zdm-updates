## 📌 نبذة عن المشروع

**ZDM** مدير تحميل بواجهة زجاجية أنيقة، يسرّع تحميلاتك ويكمل ما انقطع منها، ويلتقط الملفات والفيديوهات من متصفحك تلقائياً. يدعم تحميل الفيديو والتورنت والجدولة، ويعمل مع الـVPN والبروكسي.

## ✨ المميزات

| الميزة | الوصف |
|:---|:---|
| 🚀 تحميل أسرع | عدة اتصالات للملف الواحد وعدة ملفات معاً مع حد سرعة اختياري |
| ♻️ استئناف ذكي | يكمل من مكان التوقف حتى بعد إغلاق البرنامج ويعيد المحاولة عند انقطاع الإنترنت |
| 🌐 إضافة للمتصفح | Chrome وEdge وBrave وOpera وFirefox، تلتقط التحميلات والفيديوهات |
| 🎬 تحميل الفيديو | يوتيوب ومواقع فيديو كثيرة عبر yt-dlp مع اختيار الجودة أو الصوت فقط |
| 🧲 تورنت و Magnet | داخل البرنامج نفسه بدون برامج إضافية |
| ⏰ الجدولة | حدّد اليوم والساعة ليحمّل بصمت وأنت نائم |
| 🗂️ تنظيم تلقائي | فيديو، موسيقى، برامج، مضغوطات، مستندات، صور، مع صيغ مخصصة |
| 🛡️ VPN والبروكسي | HTTP وSOCKS5 أو بروكسي النظام تلقائياً |
| 📋 مراقبة الحافظة | انسخ رابطاً ويقترح عليك تحميله فوراً |
| 🔔 أيقونة بجانب الساعة | تعرض التقدم والسرعة والوقت المتبقي مع إشعار عند الاكتمال |
| 🎨 مظهر ولغات | داكن وفاتح، وأربع لغات تتبدّل فوراً |

## 🖥️ المتطلبات

- Windows 10 / 11 (64-bit)
- إنترنت أول مرة لتنزيل أدوات الفيديو والتورنت تلقائياً

## 📥 التثبيت

1. حمّل `ZDM-Setup-1.2.3.exe` من صفحة **Releases** وثبّته.
2. للمتصفح: ثبّت الإضافة من مجلد `browser-extension` (أو `browser-extension-firefox` لفايرفوكس) عبر صفحة الإضافات.
3. تأكد أن المنفذ في إعدادات البرنامج (`6801`) يطابق المنفذ في الإضافة.

## 🛠️ التقنيات المستخدمة

C# · WPF · .NET 8 · yt-dlp · ffmpeg · aria2 · Deno · Inno Setup

## ⚖️ الترخيص والشكر

يستخدم ZDM أدوات خارجية منفصلة وقت التشغيل، لكلٍّ منها رخصته: **yt-dlp** · **ffmpeg** · **aria2** · **Deno**. البرنامج غير تابع لأي منها ولا ليوتيوب أو Google.

> ⚠️ استخدم البرنامج لتحميل المحتوى المسموح لك فقط.

## 🇬🇧 English

</div>

**ZDM** is a fast and smart download manager for Windows with a sleek glass UI.

- 🚀 Multi-connection downloads with smart resume and auto-retry
- 🌐 Browser extension for Chrome, Edge, Brave, Opera and Firefox
- 🎬 Video downloads via yt-dlp, 🧲 torrents and magnet links via aria2
- ⏰ Scheduler, 🗂️ auto organization, 🛡️ VPN / proxy support
- 🎨 Dark & light themes, 4 languages (Arabic · English · Русский · 中文)
- 💻 Windows 10 / 11 (64-bit) — download the installer from **Releases**
